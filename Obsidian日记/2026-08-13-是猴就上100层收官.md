# 2026-08-13 是猴就上100层阶段收官

## 正式入口与唯一事实源

- 游戏名：是猴就上100层
- 正式入口：https://monkey.myskme.com/
- 现役版本：`20260813.4-solo-tea-newart-bugfix`
- 正式仓库：`myskme/myskme-hub`
- 运行正本：`monkey/index.html`
- 发布方式：合并 `monkey/**` 或 `deploy/monkey/**` 到 `main` 后，由 GitHub Actions 构建并发布至 EdgeOne Makers 的 `monkey` 海外区项目。
- 灾备副本不是正式发布源，不得反向覆盖正本。

## 本阶段已经成立的体验

- 单人无限上楼，保留平台可达性、角色可见性看门狗、坠落冻结与鱼式救援。
- 五种帮助道具、八类轮值任务、档案章、四套开工装备和长期存档。
- 十六个长期称号、二十款奶茶、十三种随机意外和五个固定高度暗号。
- 1080 x 1350 成绩海报，自带正式域名二维码、本局印记、职级、佩戴称号、奶茶和六档随机版式。
- Web Audio 原生音乐与音效、三档声音控制、低功耗调度和防爆音限制器。
- 手机铺满、安卓宽虚拟视口兜底、添加到桌面、离线冷启动。
- 多人模式已经拆除，当前作品只保留单人模式。

## 不能再漂移的角色口径

- 鱼小姐是绿鲤鱼成精，主色为 `#3fab84`。这个世界不存在金鲤鱼，`fill="#e3ad32"` 为禁用色。
- 红鲤鱼帽必须为红色 `#e0452c`，它只是一顶装饰帽，不改变任何分数、香蕉或能力数值。
- 状态类名只能用 `carp-hat-on`，资源类名为 `carp-hat`，二者不能同名。
- 猴先生、鱼小姐、驴、蛇和蛋的唯一事实源是 `monkey/index.html` 内的 SVG 与构建断言，不在角色大宝典或 `characters.json` 中。
- 猴先生与鱼小姐的关系只留在细节里，不在文案中解释。

## 收官门禁

每次发布前至少执行：

```text
node monkey/tools/extract-assets.mjs --check
node deploy/monkey/build-edgeone-monkey.mjs /tmp/myskme-monkey.zip
node deploy/monkey/verify-online-monkey.mjs
```

改动视觉时还要完成桌面视口与 390 x 844 手机视口截图；门禁新增后必须故意破坏一次，确认它真的会失败。

## 下一阶段任务池

这次是现役版本阶段收官，不代表创作停止。王老师在 2026-08-13 追加的下一阶段目标如下：

- 重画蛇、蛋与驴：蛇就是蛇，不再连着蛋；蛋去掉英文 `egg` 与红线；驴更像驴，保持治愈、简洁和自然幽默。
- 把首页、图鉴、榜单和结算改为固定视口内的分页或分层交互，不依赖整页上下滚动。
- 增加上一最佳高度线、破纪录反馈，以及失败也能积累的长期成就。
- 设计世界排行并验证本地先存、弱网补传、重试确认和回榜一致性。
- 扩展分享海报的随机样式、稀有彩蛋与可持续内容池。
- 长期把东西方文化自然地融入事件、文案与视觉，不做生硬标签或刻意抛梗。

以上新增事项要独立分支、独立 PR，不与四单收尾混在一起，也不改动环屏碰撞判定或既有解锁阈值。
