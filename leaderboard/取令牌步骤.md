## 1. 创建令牌

打开 **https://dash.cloudflare.com/profile/api-tokens** → 右上「**Create Token**」
→ 拉到最下面点「**Create Custom Token**」右边的 **Get started**。

按这个填：

| 项 | 填什么 |
|---|---|
| **Token name** | `gemfall-deploy-0729`（随便起，方便你事后认出来吊销） |
| **Permissions** 第 1 行 | `Account` · `Workers Scripts` · **Edit** |
| **Permissions** 第 2 行 | `Account` · `D1` · **Edit** |
| **Account Resources** | `Include` · 选你那个账号（ID 结尾是 `…d55c`） |
| **Client IP Filtering** | 留空 |
| **TTL** | 建议设成 **今天到明天**，过期自动失效，忘了吊销也不怕 |

点 **Continue to summary** → **Create Token** → 复制那串令牌（**只显示这一次**）。

> 两条权限缺一不可：`Workers Scripts:Edit` 用来上传 Worker 代码，
> `D1:Edit` 用来建矿脉榜的新表并跑迁移。

## 4. 我会做的事

```bash
python3 leaderboard/deploy.py
```

它会依次：

1. **D1 迁移**（幂等，重复跑不会重置赛季起点）
2. **上传 Worker**，同时写入四个 secret：
   - `LB_SALT`（沿用 `.lb_salt`，保证老玩家的设备键连续，不会掉榜）
   - `LB_ADMIN_HASH` ← **现在会写当前管理口令的哈希**（详见下方⚠）
   - `LB_CLASS_HASH` ← 小队口令的哈希
   - `LB_KILL=0`（急停开关，留着以备不时之需）
3. 我再冒烟验一遍：
   - `GET /` 应返回 `v:4` 且 `games:["wordduel","gemfall"]`
   - `GET /gf/board?scope=world` 应返回 `ok:true` 的空榜
   - 游戏里点「矿脉榜」应该能起名上榜

## 5. 用完吊销

回 https://dash.cloudflare.com/profile/api-tokens，找到你起的那个名字 → **Delete**。
（如果第 1 步设了 TTL，到期会自动失效，但手动删更干净。）

我这边部署完会执行：

```bash
shred -u /tmp/cf_tok 2>/dev/null || rm -P /tmp/cf_tok
```
