# 取 Cloudflare 令牌 · 部署矿脉榜后端

## 推荐：建一个长期令牌，建一次一直用

以前每次部署都要重新建、用完吊销，太折腾。现在改成长期令牌放在
`~/.cf_tok`，脚本自动读，**以后部署就是一条命令**。

权限只给两条，已是最小集：它只能改这一个 Worker 和它的库，
**改不了域名、动不了别的服务、也看不了账单**。

### 建令牌（只做这一次）

1. 打开 <https://dash.cloudflare.com/profile/api-tokens>
2. **Create Token** → 最底下 **Create Custom Token** 的 **Get started**
3. 按这个填：

| 项 | 填什么 |
|---|---|
| Token name | `myskme-deploy`（长期用，不用带日期） |
| Permissions 第 1 行 | `Account` · `Workers Scripts` · **Edit** |
| Permissions 第 2 行 | `Account` · `D1` · **Edit** |
| Account Resources | `Include` · 你的账号（ID 结尾 `…d55c`） |
| TTL | **留空**（长期有效） |

> ⚠ 用官方模板「Edit Cloudflare Workers」更快，但**必须手动补上 D1 Edit**。
> 踩过一次：少了 D1 权限时 `verify` 接口照样显示「有效」，
> 因为它只验令牌真伪、不验授权，直到真正调用才报 7403。

4. 复制令牌（只显示这一次），在**你自己的终端**里执行：

```bash
printf '%s' '把这七个字换成真令牌' > ~/.cf_tok && chmod 600 ~/.cf_tok && echo "已写入 $(wc -c < ~/.cf_tok) 字节"
```

**应该显示 50 字节上下。** 显示 21 就是把上面那句中文原样存进去了
（真踩过），重来一次即可——脚本现在也会拦下这种情况并提示。

嫌粘贴麻烦可以用这条，不回显、不进命令历史：

```bash
read -rs -p "粘贴令牌后回车: " T && printf '%s' "$T" > ~/.cf_tok && chmod 600 ~/.cf_tok && unset T && echo "已写入 $(wc -c < ~/.cf_tok) 字节"
```

### 以后每次部署

```bash
python3 leaderboard/deploy.py
```

没了。脚本会自己找令牌、检查文件权限、做 D1 迁移（幂等）、上传 Worker。

## 安全边界（明说清楚）

- 令牌是**明文存在你自己电脑上**的，靠 `chmod 600` 保护（只有你读得到）。
  脚本每次跑都会检查权限，不是 600 就拒绝执行。
- 权限只有两条，**只能碰矿脉榜这一个 Worker 和它的 D1 库**。
  就算泄露，别人也改不了你的域名、发不了邮件、看不了账单。
- `~/.cf_tok` 在仓库外，**不会被 git 提交**。
- 想作废随时去控制台 Delete，重建一个覆盖写进去即可。
- **令牌不要贴进聊天框**——贴过就等于公开了，必须吊销重建。

## 老流程仍然可用

一次性令牌放 `/tmp/cf_tok` 照样能跑，脚本会先找 `~/.cf_tok`、
找不到再找 `/tmp/cf_tok`。临时授权给别人部署时用这个更安全。

## 部署都做了什么

1. **D1 迁移**（幂等，重复跑不会重置赛季或清数据）
2. **上传 Worker**，同时写入四个 secret：
   - `LB_SALT`（沿用 `.lb_salt`，保证老玩家设备键连续、不掉榜）
   - `LB_ADMIN_HASH` ← 从 `console/index.html` 的 `PW_HASH` 动态取，
     以后轮换口令会自动跟上，脚本里不留明文
   - `LB_CLASS_HASH`
   - `LB_KILL=0`（急停开关）

部署后建议冒烟验一遍：

```bash
curl -s "https://myskme-leaderboard.wzc1020.workers.dev/gf/camps"
curl -s "https://myskme-leaderboard.wzc1020.workers.dev/gf/board?scope=world&limit=2"
curl -s "https://play.myskme.com/api/gf/camps"
```

第三条是国内门（EdgeOne 网关），新路由要在**网关白名单**里才通——
白名单有**正副本两份**：正本 `deploy/gateway/api/`、副本 `match/edge-functions/api/`，
**改正本再 cp 同步**，主页构建有守卫会拦下不一致。
