# 矿场 · 兑 —— 货架与定价定案

2026-08-04 定。数据全部来自线上 D1 真实档案，不是估的。

## 三条店规（开工前先读，改商品也先读）

1. **店里不卖战力。** 判据是机械的：任何商品**不得改写 `pwLines()` 读的那九个字段**
   （lv / stars / chain / mv / score / rush / days / runs / dbest）。会改，就不上架。
   这比「感觉像不像战力」硬得多，不用每次重新辩论。
2. **绝版的代价只能是「做到」或「在场」，不能是货币。** 岁记那句「过月永不再得」
   不许被任何商品赎回——补铸一旦存在，别人已经拿到的实铸当场贬值。
3. **任何进度只写绝对数**（已拓 12 张），不写百分比、不写分母、不写缺口。
   成绩只增不减，而百分比会在每次上新内容时集体掉下去。

## 分工：矿力控节奏，灵力控取舍

- **矿力是门槛，永不扣减**（它是排名依据，扣了榜单/贴身对手/阵营贡献一起崩）
- **灵力与星屑是货币**，决定你先买哪件

## 灵力的实际产出（从代码算的）

| 来源 | 每天 |
|---|---|
| 每日矿灯 `200 + min(连续,10)×100` | 200 → 1200 |
| 今日三桩 三条 × 150~260 | 约 600 |
| 通关 `分/100`、失败 `分/150` | 约 1200 |

**合计约 3000 灵力/天**，正好等于一个典藏匣的价（匣每天限 2，说明设计上就是这个量级）。
定价一律按「几天的收入」来读。

## 定价原则

| 层 | 价位 | 换算 |
|---|---|---|
| 矿口架 | 600 ~ 900 | 不到一天 —— 第一天就该买到东西，这是钩子 |
| 浅脉 / 中脉 | 2,000 ~ 6,000 | 一到两天 |
| 深脉 / 暗河 | 5,000 ~ 12,000 | 二到四天 |
| 断层以上 | 6,000 ~ 15,000 | 二到五天 |

底层刻意便宜：**期待感由锁着的上层提供，不该由「买不起」提供**。

## 明确不做的

| 砍掉 | 为什么 |
|---|---|
| 月纹装帧（每月上架、下月不回归） | 限时购买窗口。不写倒计时玩家也会自己数日子，等同焦虑倒计时 |
| 岁记补铸 | 用钱买回绝版，线上已有的实铸当场贬值 |
| 灵石刻法·烛照（六色全暖金） | 辨识度一降连锁打不出来，而技巧线是**平方地掉**，等于花钱买 debuff |
| 石痕·矿道格 | 伪装成外观的战力（看清列＝更容易连锁）。改成**免费发给所有人**，店里标「不售·已赠」 |
| 灵器刻纹 | 图标很小、局内一闪、别人看不见，还得写免责声明才敢卖 |
| 窖藏印的清零条款 | 全表唯一的清零机制，撞死「不做惩罚式设计」 |
| 便利品：灵器 / 灯油 / 续关 | **一件都不卖，永远不卖。** 按店规第一条直接判：它们改 chain/rush/score，全在那九个字段里。「差一口气」的正解已经在结算页的续挖（局内、当场、每关封顶 2 次） |
