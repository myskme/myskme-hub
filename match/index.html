ADD TO HOME SCREEN

  
安装到手机

  
加到桌面后：全屏无地址栏、有独立图标，像 App 一样点开就玩。

    记住正门：play.myskme.com
    —— 告诉朋友这一个就够

  

    
iPhone / iPad（用 Safari 打开本页）

    
1点击屏幕底部中间的分享按钮
      
      （方框加向上箭头）

    
2在弹出的菜单里向下滑，找到「添加到主屏幕」并点它
      

    
3点右上角「添加」——桌面上就多了灵石图标

    
用微信/QQ 打开的话，先点右上角「···」选「在 Safari 中打开」，再照上面做。

  

  

    
安卓手机（用 Chrome / 系统浏览器打开本页）

    
1点右上角的菜单按钮
      
      （竖排三个点）

    
2点「添加到主屏幕」（有的手机叫「安装应用」）

    
3点「添加」或「安装」确认——完成

    
华为/小米等自带浏览器菜单位置略有不同，一般都在菜单里找「添加到桌面」。
      微信里同样先选「在浏览器中打开」。

  

  
  

    
换设备 / 手机平板换着玩

    
进度存在这台设备上。换设备时把口令复制过去，
      两边都能接着玩。全程离线，不经过任何服务器。

    

      
      
    

    
这一页还有两个入口：玩法页里的「导出 / 导入进度口令」，
      和成就页底部的「换设备」。
