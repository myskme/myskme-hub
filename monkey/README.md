# 是猴就上100层

MYSKME 荒诞休闲系列第一作。正式入口为 https://monkey.myskme.com/ 。

## 唯一源码

- monkey/index.html 是游戏逻辑与游戏内美术的唯一运行正本。
- 游戏本体无外部脚本；成绩海报二维码仅调用随站发布的 `vendor/qrcode-generator.js`（MIT）。世界楼榜只经 `https://myskme.com/api/monkey` 品牌网关读写，断网不影响游玩。离线完整运行需保留 `index.html` 与 `vendor/`。
- manifest.webmanifest、sw.js、vendor/ 与 icons/ 提供“添加到桌面”、独立窗口、二维码海报和正式域名离线冷启动。
- reusable-assets/ 是由正本自动导出的可复用矢量资源，**整个目录都是生成物，不允许手工修改**；
  其中的 README.md、asset-manifest.json 也一样，下次生成会整个覆盖。
- tools/extract-assets.mjs 负责导出角色姿势、配角、道具、奶茶、八种世界窗景和封面，并生成带 SHA-256 的总账、
  调色板、画风参数（从正本现数，不手写）与二创须知。**发布门禁会跑它的 `--check`**，
  改了正本美术却没重跑导出器，构建直接失败——所以镜像不可能悄悄过期。

## 当前系统

- 声音：Web Audio 原生合成的荒诞办公室爵士，随高度、连跳、部门与危险状态改变编曲；支持“乐＋效 / 仅音效 / 静音”，不下载外部音频。
- 复玩：五种帮助道具、八类轮值任务、档案章与四套开工装备；连跳上限 `FLOW_CAP`；使用 `myskme_monkey_career_v1` 保存长期档案，旧最高分与排行榜键保持兼容。
- 目标：开局冻结上次最高高度，接近时在楼内显示目标线；首次越线只庆祝一次，旧线立即撤下。结算仍同时保存高度与分数纪录。
- 世界楼榜：本周高度、生涯高度、不白摔三榜。本周榜按北京时间周一零点换周；不白摔榜按正式局数、累计米数排序，让每次失败仍留下长期进度。首次由玩家主动登记，之后正式局先写本机队列再自动补交；单局编号精确回执，重传不重复累计。
- 世界窗景：江南雨窗、北欧薄暮、丝路晨光、地中海午后、和纸月夜、包豪斯清晨、安第斯风带与靛蓝鼓点共八种。正式局使用持久化洗牌袋，一轮看完前不重复；完成一局才记入长期档案。窗景只改变气氛，不改变数值。
- 暂停：局内可随时暂停（按钮、Esc 或 P），切后台自动暂停。暂停会把本局所有绝对计时整体后移，
  道具与事件倒计时的剩余时长原样保留，暂停不能当作弊入口。返回主菜单需二次确认。
- 称号：十六个长期解锁称号，存在 `myskme_monkey_career_v1` 的 `titles` / `worn` / `tally`；
  可挑一个佩戴，会印在成绩海报上。与结算页按高度评的五档职级是两回事。老存档缺这几段按 0 起算，不清档。
- 奶茶图鉴：二十款，存 `teas` / `cup`，按「本局做过什么」解锁（踩过哪种台、用过哪件道具、到过哪层、
  被谁盖过章）。三套收集的分工是死规矩，别混：**意外图鉴＝你遇到了什么，称号＝你是谁，奶茶＝你喝到了什么**。
  自检里有一条「奶茶与称号的解锁条件不重叠」，就是防止它退化成称号的复制品。
- 单人：本作只有单人模式。2–6 人同机轮流赛已于 0813 整体拆除，发布门禁会拦住它被悄悄加回来；
  游戏内文案也不再出现「单猴」这类以多人为参照的说法（0814 校对过一轮）。
- 香蕉商店：十八件行头、六个槽位（头顶/脸上/脖子/手上/背上/座驾），猴子真的穿上开上，
  并印上成绩海报的名片照。全部纯外观，一个数值都不碰（发布门禁盯着）。定价按实测收入推，
  阶梯形状（相邻档 2–4 倍）也有门禁守着。
- 收藏条：首页九格——称号、奶茶、行头、任命、纸型、意外、窗景、立面、调式，点格子直达对应图鉴。
- 任命排：局内每约一公里出一排三块台，落到哪块拿哪份任命，另外两份作废淡出；
  「最近的一份总够得着」有自检盯着。
- 气氛：十二部门各配一种建筑立面与一种调式（一个部门一门学问），与八种窗景、六种海报纸型
  独立组合；全部只改气氛，不改数值。
- 玩笑：随机意外「红鲤鱼帽」会让猴先生假扮红鲤鱼，驴当场说「仿的」。纯装饰，不改任何数值。
- 平台：除绕口令词牌与标点机制外，台阶不再写说明文字，统一用轮廓、材质、色彩、运动和破坏反馈表达规则。
- 分享：结算页生成 1080 × 1350 图片海报，包含本局防篡改感印记、成绩、二维码、七档职级、当前佩戴称号与奶茶定制单。六种按权重抽取的版式与八种窗景独立组合，形成 48 种基础视觉组合；同一次分享页连续重抽不会出现完全相同的组合。Web Share 支持时直接分享图片，否则可长按保存。
- 惊喜：十三种洗牌式小意外与 404、555、888、1314、2026 米暗号彩蛋；图鉴只记录正式单人局，测试局不污染存档。
- 全屏：手机上游戏外框铺满整个视口（`@media(max-width:699px)`），只在超长设备上按 2.5:1 收一下防止角色被拉长。
  桌面（≥700px）仍保持 460 宽的「手机框」造型。刘海与 Home 指示条靠 `viewport-fit=cover` + `env(safe-area-inset-*)` 让位。
  iPhone 必须用 Safari 的「添加到主屏幕」才是独立全屏应用，用别的浏览器加出来的只是书签——安装说明页第一条就写着这句。
- 兼容：针对部分安卓浏览器约 980px 的宽虚拟视口进行触屏竖屏放大兜底；鱼式救援会上推约 20 米并留下三秒临时泡泡台。
- 性能：触屏设备最高按 50 fps 更新，菜单与结算停止主循环，页面隐藏时停止音乐和动画循环，空闲 AudioContext 自动挂起；混音总线带压缩限制器与渐入渐出包络。
- 安全：测试 URL 参数不写入长期档案；角色可见性看门狗、坠落冻结与完整 SVG 角色钳制继续作为发布门禁。

## 更新

1. 只修改 monkey/index.html。
2. 运行 node monkey/tools/extract-assets.mjs 更新可复用资源。
3. 运行 node deploy/monkey/build-edgeone-monkey.mjs /tmp/myskme-monkey.zip
   （它自己会跑 tools/extract-assets.mjs --check，不必再手动跑一遍）。
4. 合并进 main 后，GitHub Actions 自动发布到独立 EdgeOne 项目 monkey（海外区，项目 ID makers-tf8nmwxqv8bq）。

首次上线需要在 EdgeOne 为项目绑定 monkey.myskme.com 并在 DNSPod 添加 CNAME；
此后发布不再需要碰控制台。
